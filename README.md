# MBGA

A companion mod for **Create Crafts & Additions (1.2.6)**.

- Compatible with Minecraft **1.20.1** + Fabric Loader **0.17.2** + Create Fabric **0.5.1-j-build.1631+mc1.20.1**.
- Runtime dependencies: `create` (≥0.5.1-j-build.1631), `createaddition` (≥1.2.6), `farmersdelight` (≥1.20.1-2.4.0), `createoreexcavation` (≥1.5.4), `create_enchantment_industry` (≥1.2.16);
